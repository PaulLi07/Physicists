# 本轮检索与对照的资料库

检索日期：2026-10-26。下列目录用于发现遗漏与建立来源入口；日期、贡献和人物身份仍回到具体传记、档案或论文核实，未把任何单一网站视为不会出错的总表。

| 网站 | 本轮用途 | 范围与注意事项 |
| --- | --- | --- |
| [AIP Physics History Network](https://history.aip.org/acapsearch/) | 物理史人物与机构传记入口 | 包含人物与机构历史，不能把全部条目机械地当作本库应收录的人物 |
| [AIP Oral History](https://www.aip.org/history/oral-history) | 科研履历、合作关系与口述史来源 | 用于补充背景；访谈日期不能当作生卒日期 |
| [MacTutor，圣安德鲁斯大学](https://mathshistory.st-andrews.ac.uk/) | 数学物理、力学、光学与早期人物的传记和遗漏对照 | 页面简表与正文偶有矛盾；本轮对生日、逝世日、受洗日及历法差异另行交叉核对 |
| [National MagLab：Pioneers](https://maglabweb.magnet.fsu.edu/magnet-academy/history-of-electricity-magnetism/pioneers/) | 同类电磁学先驱人物网页；对照本轮读取的66个目录入口 | 补入重要实验与电子技术人物；汽车与一般工业发明不自动等同于核心物理贡献 |
| [诺贝尔奖官方结构化数据](https://api.nobelprize.org/2.1/laureates?nobelPrizeCategory=phy&limit=1000) | 核对截至2026年的230位物理学奖得主、获奖年份与获奖时机构 | 官方结构化日期仍可能滞后或与本国档案不一致；已记录具体修订依据 |
| [Wolf Foundation](https://wolffund.org.il/home-page/) | 发现非诺奖实验物理和精密测量贡献者 | 首页存在重复模板内容，个人人物仍用机构传记核对，不能依据错误模板归类 |
| [ICTP Dirac Medal](https://www.ictp.it/home/dirac-medal) | 现代非诺奖理论物理贡献者的遗漏对照 | 奖项用于检索入口，不将是否获奖作为收录的唯一标准 |
| [英国皇家学会档案目录](https://catalogues.royalsociety.org/) | 生卒、成员身份及传记线索 | 与本国档案存在分歧时保留双方来源 |
| [瑞典国家档案馆人物传记](https://sok.riksarkivet.se/sbl/) | 复核瑞典人物日期及历年研究履历 | 本轮用于核实曼内·西格巴恩等人物的来源冲突 |

本轮还使用大学、研究机构、科学院、博物馆、国家图书馆和同期纪念文。具体链接、访问状态、修订理由及未定问题保存在 `data/audit/` 与各人物档案中。

“全网检索”在此指跨多个独立资料体系开展广泛检索与逐人交叉核对，不能理解为已经穷尽互联网上的每个页面或物理史上的全部贡献者。名录仍保持开放扩充。
