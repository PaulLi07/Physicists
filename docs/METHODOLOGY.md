# 收录与史料规范

## 范围与来源

本档案按出生时间组织，选择在力学、热学、电磁学、光学、量子物理、相对论、统计物理、凝聚态、粒子与核物理、天体物理等领域具有重要历史贡献的人物，并纳入相应的数学物理、仪器与实验先驱。古代和中世纪人物以物理相关贡献收录，不能将当代职业分类机械地套用到他们身上。

诺贝尔物理学奖部分以 [诺贝尔奖官方 API](https://api.nobelprize.org/2.1/laureates?nobelPrizeCategory=phy&limit=1000) 为结构化依据，保存原始响应；同一人多次获奖合并为一个档案。简介中的“获奖时任职机构”严格指官方资料的获奖当年机构，不能理解为完整教育或任职履历。

非诺奖人物优先参考大学、学会、研究机构及 [圣安德鲁斯大学 MacTutor](https://mathshistory.st-andrews.ac.uk/) 的人物资料；Wikipedia 用于交叉查核与图片身份匹配，Wikidata 用于辅助识别。来源是史料入口，不代表所有历史争议已有定论。各条目保留具体参考链接；第三方内容不作为脚本指令执行。

中文内容是简明的历史资料摘要，贡献列表只列代表性成果，不能代替学术传记、论文目录或对于优先权争议的专门研究。不同人的篇幅有差异，诺奖群体的部分简介由官方出生地、获奖时机构等事实整理成简短生平。

## 日期

- 以出生日期升序排列；日期只精确到年时，以该年起点作为排序键，不代表实际出生于1月1日。
- 负数年份表示公元前，如 `-0287`；此项目沿用历史纪年，无公元0年。
- `precision` 分别记录确日、年月、确年或约年。古代约年不扩写成虚构月日。
- `display` 保留中文“约”“公元前”等提示；争议与历法差异写入 `notes`。
- 不对所有历史人物的旧历日期自动换算；牛顿等明确换算的情况在人物条目说明，其他条目保留来源惯例。因此同一时期的确日比较可能涉及历法差异。
- `death: null` 本身不表示在世，必须结合 `death_status`。失踪与死亡日期不确定的人物应为 `unknown`。
- 在世状态是本次整理所据公开资料的状态，不构成未来状态保证；后续维护时需更新。

## 肖像

使用真实存在的公开文件及其描述页，下载副本供本地档案浏览。尽量采用 Wikimedia Commons 中已有许可说明的文件；没有用生成式模型伪造人物照片。

古代和部分早期近代人物没有可验证的生前肖像。档案中后世创作的头像、雕像、纸币或纪念像只表示传统或纪念性形象；极少数人物仅存相关文献或仪器图像时，应明确列作资料图，不能声称是本人肖像。图像类别见 `portrait.kind` 与 `portrait.depiction_note`。

文件记录原图页面、作者、原始来源说明、许可名称、许可链接、下载地址、整理日期及 SHA-256。图片描述页声明为公共领域时，其判定可能有地域条件，详细条件见原文件页。后续发布时应完整保留适用的署名与许可信息，不能把 Commons 页面的默认文字许可误当成该图片的许可。

## 已知边界

本次通过人物来源、日期精度、JSON字段、排序、重复人物、图片文件及许可信息的检查建立可用的初始库。名录开放扩充，跨领域身份边界、译名、史学解释和成果优先权仍可进一步考证。新增或修改人物时应保留来源与争议说明，避免把历史发展归结为单个人的孤立成就。
