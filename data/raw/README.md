# 原始资料与本地缓存

Git保留 `nobel-laureates.json`，作为离线档案构建所需的诺贝尔奖官方数据快照；同时保留 `sourced-portraits/` 中手工图像匹配需要的来源文件，以及补充图片复核记录 `final-image-qa-modern.json`。

除上述明确保留的文件外，本地检索产生的HTML、PDF、日志、重复原图及采集缓存由项目根目录的 `.gitignore` 排除，继续保存在原有本地目录。人物参考链接、已复核事实、图片署名和权利信息、逐人复核记录、最终配图及两版完整档案均纳入版本管理。

克隆仓库后，可直接浏览已有网页和档案，也可运行离线构建脚本。重新进行网络采集时，`scripts/harvest.py` 和相关脚本会重新取得可访问的来源并创建缓存；网络状态和图片授权条件仍以各来源为准。
