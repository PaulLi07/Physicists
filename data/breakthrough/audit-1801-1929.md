# 1801–1929 年物理突破事件审查记录

审查日期：2026-10-26。数据文件：`events-1801-1929.json`。

## 范围与结果

本批收录 101 个事件，涉及 95 位现有档案人物，使用 149 个不同来源 URL。按首次公开报告或发表节点排序；不是按出生年份、诺贝尔奖年份或网页档案人数生成。覆盖力学、光学与电磁学、热力学与统计物理、物质、量子起源与量子力学、核与粒子、天体物理及实验方法。

此数据是有来源的编辑选集，不声称穷尽本时期所有物理成果。欧洲与北美文献、已有档案及可在线核查资料占比高，存在地区、语言、存档与学科偏差。没有为每位人物凑一个事件，也没有用事件数量代表个人排名；未入档协作者以 `groups` 文字记载。

评分分布：1 分 1 项；2 分 37 项；4 分 56 项；8 分 7 项。各档语义分别为重要推进、重大方法/模型/现象、领域奠基、基础框架变革。分值是本项目透明的编辑判断，不是文献记载的客观数值或专家共识。高分不因后来的获奖而提高。这个筛选本来就偏重里程碑，因此不可据此推断任一年代的全部科研产出。

## 核查办法与来源

1. 先核对 `data/timeline.json` 的人物 ID，再参照 `website/dist/data/archive.js` 中的档案与来源；事件来源另行搜索，不直接把人物生平中的所有日期转换为事件。
2. 按事件检索原始论文及其出版社元数据、皇家学会原始会议/论文档案、大学图书馆和科研机构史料；用 APS、AIP、Nobel 官方历史资料及大学专题交叉核对。
3. 同一发现、多作者、连续论文、同一理论的不同表达合并为一个成果族。具有新增物理知识的独立实验验证可以另列；实验验证的评级针对其新增内容，而非重复计算原理论的影响。
4. 原始论文或机构记录与后来的简史有差异时，优先能明确解释公开/出版节点的史料，并写入 `dateNote`。不把书目中的 DOI 字符年份机械地作为出版年份。
5. 逐项检查中英文标题、理由及定年说明是否一致，检查 ID、必需字段、领域、枚举、年份范围和人物引用。所有 4/8 分事件至少附两个来源；来源数量本身不等于彼此独立，许多二级来源与原始论文配合使用。

实际使用的主要来源包括：

- [皇家学会 Making Science](https://makingscience.royalsociety.org/)：Young 1801 年宣读、Maxwell 1864 年宣读等原始节点；原始论文 DOI 用于 Hamilton、Poynting、Reynolds 等事件。
- [University of St Andrews MacTutor](https://mathshistory.st-andrews.ac.uk/)：Green、Hamilton、Fourier、Ohm、Coriolis、Stokes 等人的论文与工作年代。
- [APS Physics History](https://www.aps.org/apsnews) 与 [AIP Einstein exhibit](https://history.aip.org/exhibits/einstein/quantum1_text.htm)：奥斯特、Faraday、Carnot、Foote、电子、Noether、Bose–Einstein、受激辐射等历史节点。
- Florida State University 光学史表：[1800–1833](https://micro.magnet.fsu.edu/optics/timeline/1800-1833.html)、[1834–1866](https://micro.magnet.fsu.edu/optics/timeline/1834-1866.html)、[1867–1899](https://micro.magnet.fsu.edu/optics/timeline/1867-1899.html)、[1900–1933](https://micro.magnet.fsu.edu/optics/timeline/1900-1933.html)。用于发现候选与部分核对，未整表照抄；遇到简表年代与原文不一致时，以具体事件说明为准。
- [Yale Gibbs papers](https://ead-pdfs.library.yale.edu/584.pdf)、[1902 年 Nature 同时代书评](https://doi.org/10.1038/066291a0)、Smithsonian 原书/档案：核查出版与实验报告。
- [NIST Kelvin history](https://www.nist.gov/si-redefinition/kelvin/kelvin-history)、Helmholtz Association、TU Wien、DLR、NASA/NACA、Harvard CfA：温标、能量守恒、边界层、周期光度关系与恒星成分等。
- Wiley、Springer、APS、Nature、PNAS 及大学存储库的原论文/书目，用于 Planck、Einstein、Mie、Debye、Noether、Compton、Heisenberg、Born、Schrödinger、Dirac、Hubble 等；Nobel 讲演和官方历史资料辅助核对意义，不采用获奖年。

网页工具有些 DOI、Nobel 直接 facts 页面会返回访问限制，能检索到的官方书目、原文复制或索引摘要仍可核查书目信息。因此本记录不声称所有 URL 均通过 HTTP 可用性测试，也不把无法全文打开的论文描述成已完整重读。JSON 保留可追溯的标准 DOI 或机构链接。

## 机器核查

- 101 个事件 ID 唯一；所有 `people` 均存在于当前人物档案。
- 年份均为整数且处于 1801–1929；当前本批没有约略区间或未知年份。
- 所有领域、类型、权重和状态均符合项目模式；中英文必要字段、来源和定年说明完整。
- 仅修改本批 JSON 和本记录；没有改写人物档案，也没有发布网页或推送远程仓库。

`reviewed` 表示本轮核过来源、日期及条目表述；不表示历史优先权争议已经解决，也不表示权重已由物理史专家外审。新增/修订事件仍应经过同样流程。零收录的年份表示本选集没有事件，不表示那年物理学没有进展。
