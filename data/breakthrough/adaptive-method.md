# 历史自适应时间密度与独立估计分量

版本：2.0。此文件记录项目内部的可复算方法，不是对古代物理发展真实总量的无偏估计，也不把个人估计伪装成期刊已证实成果。页面可以保持简洁；源数据和本文件保留估计与来源的区别。

## 早期与近现代采用不同的概览分辨率

原始年度值保留来源的时间分辨率：明确单年的成果全部归该年；来源给定的年份区间等额分配权重。确切发表年不会被改写为“约某年代”。

主图使用按源年份变化的三角核，而不是全历史统一11年核。概览半宽 h(t) 采用以下预先规定的折点，并在折点之间线性插值：

| 源年份 | 概览半宽 |
| --- | ---: |
| 公元500年及以前 | 50年 |
| 1500年 | 20年 |
| 1800年及以后 | 5年 |

因此500—1500年逐渐从约百年尺度过渡到约四十年尺度，1500—1800年继续过渡到近现代的11年窗口。这里的宽度是历史概览的平滑分辨率，不是单篇原始文献的置信区间，也不是根据人物数或希望得到的图形倒推的系数。不会给早期成果乘以任意的时代补偿倍数。

对历史连续序数 t 的每单位原始质量，使用：

`K_t(d) = max(0, h(t)+1-|d|) / Σ_j max(0, h(t)+1-|j|)`。

整数偏移 d 覆盖全部非零核值。半宽可以不是整数，非零整数支撑最大到 `ceil(h)`；分母按该年的离散核实际求和。h=5时完全退化为原11年三角核 `(6-|d|)/36`。每个源年份分别归一化，因此增添一个正权重成果或增加重要程度都不能压低任何现有年份的值，且完整时间范围内平滑前后总质量相等。折点处的 h 连续，不出现按世纪突然更换分母的断层。

历史纪年通过连续序数换算，前1年之后是公元1年，数据中没有历史0年。输出起点包含最早来源所需的左侧核支撑；未来未到的年份不输出，也不在右边界重新归一化。最近的核支撑范围标记为暂定，因此不能把边界衰减解释为物理发展停滞。

## 真实来源与个人估计分开计算

原有 `events-*.json` 保留期刊、档案或机构来源的事件。个人估计通过独立输入 `options.estimatedContributions` 传入：

```js
{
  personId: 'stable-person-id',
  year: 1900,
  range: [1890, 1910],
  contributionFactor: 0.5,
  estimated: true
}
```

一个人最多一条估计。有已定年且参与计分的真实事件关联者，不能再加一项个人估计；否则会重复计算同一人的已记录贡献。只有未定年来源或不计分历史记录者仍可由独立估计模块生成保守的残余贡献。明确排除的错误主张不会因此变成已验证成果。单独估计不要求伪造论文、DOI或事件引用，输入人物必须存在，因子非负，代表年必须在估计区间内，区间不得超出资料截止年。

原始、平滑结果均保留分量：

- `rawObserved` / `observed`：可计分来源事件的年度原始值 / 自适应平滑值。
- `rawEstimated` / `estimated`：独立个人估计的年度原始值 / 自适应平滑值。
- `raw` / `value`：上述两个分量之和。
- `uncertain`：来源日期不确定分量与个人估计分量的平滑和；不冒充统计置信区间。

个人因子在其区间内分配，不会按每个活动年重复计入完整因子。替代权重敏感性测试只改变来源事件的等级映射；如果要比较完整混合指数，需要在两次调用中传入同一套个人估计。估计以后获得真实来源时，应替换原估计，不能与新来源同时保留。

## 颜色密度独立于突破评分与历史平滑带宽

颜色统计范围为全部有日期的档案历史事件关联人物（包括不计分的历史记录）及独立人物估计，而不是只数高评分成果作者。采用统一11年窗口，以便与成果指数的历史自适应宽核分开。

对一个人的一条日期区间 `[a,b]`，在选定11年窗口中的份额为 `交集的历史年份数 / 区间的历史年份总数`。如果是明确单年且落在窗口中，份额就是1；若区间宽达100年，不能将该人当作每年都有一项已知活动。

同一人物可能关联多条来源，取该窗口中各条来源支持份额的**最大值**。不无依据地假设日期独立，也不累加多个事件把同一人计成多人。`people` 为这类去重份额之和，可为小数；`density = people / 11`，单位为档案人物份额/年。它表达资料支持的年代分布，不是历史物理学家年度在岗人口。

## API 与验证

`BreakthroughCore.radiusAt(year, adaptive=true)` 返回连续半宽；`kernelAt(year, adaptive=true)` 返回归一化的 `[整数偏移,权重]`。`calculate(events,{historicalAdaptive:false})` 可回归原固定11年平滑。输出 `kernel` 提供折点、最小/最大半宽及人数密度口径；`components` 汇总来源事件数、个人估计数及各自总权重。

测试涵盖古代与近现代分辨率、确切原始年不迁移、完整核质量守恒、BCE/CE跨界、增加成果/因子的逐年非减、来源和估计分量分离、重复估计及真实来源重叠拒绝、宽区间人物分摊、最大份额去重，以及不计分历史人物仍进入颜色分布。
