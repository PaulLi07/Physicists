# 物理学突破指数 v2.0

本项目的指数是可复算的历史综合指标，不是期刊发布的官方评分。原始成果、出版方精选归属、来源和个人贡献估计分开保存。网页采用统一人物目录，不再设置“贡献年代待考”部分，也不展示个人估计因子的计算细节。

## 权威期刊资料

`events-journal-milestones.json` 新增48项真实文献成果：39项有出版方编辑精选归属，9项补自原始研究论文。`existing-source-patches.json` 给42项既有成果补充官方精选来源，不重复计分；`journal-sources.json` 列出6个实际使用的官方集合，包括APS的PRL/Physical Review/PRA回顾与Nature Milestones in Spin。

原始论文作者、题名、DOI和出版年份通过出版方资料及Crossref元数据核对。编辑精选用于发现遗漏和佐证，不把论文总量、引文数或期刊精选归属直接当作突破分数。访问层级、订阅限制和具体修正在 `audit-journal-milestones.md`；没有声称读完不可访问的订阅全文。

## 两类贡献分开保存

`events-*.json` 只包含有来源的历史成果。1/2/4/8是项目的编辑权重：重要推进、重大现象/模型/方法、主要分支奠基、基础框架变革。一项成果不会按作者或论文数量重复累加；独立理论与关键实验可各计一项。原始论文与报告年优先，获奖不直接加分。

未建立可计分、可定年成果关联的人物，使用 `person-estimates.js` 生成独立的保守残余估计。它们在 `contribution-estimates.json`，不写成虚构论文、不捏造DOI，也不改源档案的生卒和贡献事实。原始来源已覆盖的人不再另加个人分数；共享未知成果分摊一次预算。

估计参考已有来源人物的贡献年龄和个人分摊信用，足量时按历史时期与领域校准，样本不足再回退。年份限定在生平、最后已知活动与资料截止年范围内，采用区间而非伪造确切年份；因子设保守上限。仅有关联历史思辨记录者的小量残余不把错误主张重新标为已证实物理原理。完整校准输入、依据、分量和总量占比均保留在离线数据中。

## 早期与近现代采用不同时间分辨率

年度原始值分为 `rawObserved` 与 `rawEstimated`；来源给定日期区间和估计活动区间分别分配各自的总权重。已知确切发表年仍保留在原始年度值中。

显示采用归一化三角核。早期半宽50年；500年至1500年连续缩至20年，1500年至1800年连续缩至5年；1800年后保持5年。每个源年份的核单独归一化，保持总贡献质量，不给古代乘任意“补偿倍数”，也不因时间窗口变宽而凭空增加成果。

`observed`、`estimated`和总值`value`分别输出。主图单位仍为加权贡献点/年，横轴全时期统一线性刻度；屏幕压缩多个年份时取均值而非求和。完整公式、连续带宽和边界处理见 `adaptive-method.md`。最近年份因未来尚不可知，仍保留暂定边界。

## 人物密度与颜色

人物统计独立于成果是否计分，覆盖有历史来源的年代关联与个人估计。固定11年窗口内，每人的日期区间按覆盖份额分配，同一个人取所有来源中的最大份额去重；不假设不同来源的日期独立。密度为人物份额之和/11，因而可为小数，不把估计区间误作人物每年都在工作。

颜色严格按用户提供的ROOT RGB节点线性插值：`0→(0.9,0.9,0.9)`，`0.25→(0.15,0.15,0.15)`，`1→(1,0,0)`。不另加平方根或gamma变换。直方条连续覆盖绘图区，每个bin无描边、无间隔，零值保留零宽。

## 统一目录与自动更新

所有人物都进入贡献年代目录。有来源的导航锚点优先，缺少锚点者使用独立估计锚点并显示约年；每人仅一条。年份范围保留原始区间含义，生卒和完整档案继续可读。

```bash
node scripts/build_breakthrough.cjs
node --test website/design-review/tests/*.test.cjs
python3 website/serve.py --design-review
```

预览启动与刷新首页会检查成果、期刊来源补丁和估计模块变化后自动重算。新增人物仍先运行原有 `python3 scripts/build_website.py`，不改时间轴源码。`yearly-index.json`是逐年输出；`coverage.json`检查全部人物有导航；`sensitivity.json`在固定个人估计的条件下比较两套成果权重，不将结果误称为客观性证明。
