# 物理学突破指数 v1.0

这是本站按明确编辑规则计算的历史统计量，不是公认的物理学发展标尺。原始事件、定级理由、来源、日期不确定性和覆盖缺口均公开保存，不能用图形的低值断言某个文明或时代没有物理发展。

## 成果与权重

`events-*.json` 是唯一手工维护的成果源文件，构建程序自动发现这些文件。一条成果可以关联多位人物；论文、作者、获奖不会将同一成果重复计数。独立理论和决定性实验验证可分别计入，但评分针对各自的新增内容。没有可靠日期者保留史料，不参与年度计算。已被否定的具体自然哲学主张可使用 `indexEligible: false`，保留在目录中而不抬高指数。

编辑权重为1、2、4、8：重要推进；重大现象/模型/方法；主要分支的奠基；基础原理或理论框架变革。高档需要独立资料支持。诺贝尔奖、引用量、公众知名度和作者人数不自动加分。`rationale.zh/en` 解释选择，`status` 区分已经审阅与暂定评价。对理论提案的历史影响进行定级，不等于声明其所有物理预测已获实验证实。

日期优先采用首次公开、可核验的成果发表或报告年份；实验发生年与公开年不同者另作说明。例如引力波首次直接探测发生于2015，首次公开报告于2016。来源明确给出区间时使用 `dateRange`；约年保留来源所给估计，不从人物生卒年猜造成果年。内部将历史纪年映射为连续序数，前1年之后是公元1年，没有历史0年。

## 逐年计算

`R(y) = Σ wᵢ pᵢ(y)`。

准确到年的成果全部归该年；来源给定区间的成果将权重等分到区间内的历史年份。不能因为一项成果跨越若干年而将其权重重复相加。

主图为固定11年中心三角平滑：

`B(y) = Σ[d=-5..5] ((6-|d|)/36) × R(y-d)`。

单位为加权成果点/年；核权重和为1，保留原始年度值，且不按人物数或全库峰值归一化。最早事件前补5年以保存核的左侧质量；最近5年因未来数据尚不存在，标为暂定，不对其下降作历史结论。最新年份也可能未满全年。

颜色为同一11年窗口内参与可计分成果的**已建档人物去重数/11**，不估计合作组未具名成员。来源日期区间内的人物可能参与该窗口，不能据此解释为准确的逐年在岗人数。图形压缩多年时，条长及密度均取年度均值，不求和。

## 人物导航

每个人只出现一次。优先采用可靠定年的成果，再按较高权重、较早年份选择导航锚点。范围日期使用区间中点定位，列表仍显示完整范围；它不是确切成果年。其他成果仍参与指数。没有可靠日期关联的人物进入“贡献年代待考”，原档案完整保留。

## 构建、数据与核验

```bash
node scripts/build_breakthrough.cjs
node --test website/design-review/tests/*.test.cjs
```

`yearly-index.json` 是可复算的逐年输出；`coverage.json` 列出已有锚点与待考人物；各阶段 `audit-*.md` 记录来源核对和限制。`sensitivity.json` 比较两套合理编辑权重的结果，避免只用一种权重判断高峰。

浏览器数据写入 `website/design-review/data/`。运行 `python3 website/serve.py --design-review` 时自动构建；已有预览服务刷新首页时也会检查事件文件和人物数据是否改变，并按需重新计算。新增人物仍先走原有双语档案构建流程 `python3 scripts/build_website.py`，不需要修改时间轴源码。
