# 全库复核与双语档案报告

整理日期：2026-10-26。原库531人，本轮新增190人，现有中文、英文各721份独立档案，按出生日期排列。原有531人的档案全部保留。

## 检索与事实复核

本轮重新检索并对照AIP物理史资料、MacTutor、National MagLab同类先驱网页、诺贝尔奖官方数据、Wolf Foundation及ICTP等入口，随后回到大学、研究机构、国家档案、科学院传记和论文核对具体人物。访问受限、来源矛盾和未确定的日期均保留记录；没有把搜索结果摘要或单一目录视为最终事实。

原有档案逐人检查身份、生卒日期及精度、生平、主要贡献、合作归属、图片和来源。诺贝尔物理学奖230位独立得主另以官方名单核对，重复获奖者合并。National MagLab本轮目录的66个入口中收录63人，另3人按一般工程或医学器械贡献边界说明排除。本轮新增涵盖早期光学、力学、热学、电磁实验、核物理、场论、凝聚态、天体物理及女性和非诺奖贡献者。

## 主要修订

- 区分出生、受洗、逝世和安葬日期；例如帕潘、乔治·格林的仪式日期与未知的确切生卒日分别陈述。
- 核对旧历与公历、来源正文与简表冲突；对哈雷、雷诺、杜恒、寺田寅彦等人的日期作修订或说明。
- 用档案或机构资料纠正冯·劳厄、加博尔、贾科尼、格林贝格等人的日期；曼内·西格巴恩、杨振宁等来源分歧仍明确展示，不把分歧删去。
- 修订费马原理的驻值表述、斯托克斯位移的通常条件、切伦科夫效应的介质相速度阈值、霍尔丹链的适用模型，以及共同发现、实验条件与贡献归属等文字。
- 检查勒让德、普雷沃等易同名误配图像，区分仪器图、归属存疑画像、合影、后世纪念邮票与本人肖像；保留逐图来源和许可条件。

与基线比较，150份原有档案发生文字、来源或图片元数据更新，其中15份涉及日期数值、精度、显示或生死状态。此数包含限定说明和格式修订，不能解释成发现了同样数量的事实错误。

## 英文版再次复核

英文草稿完成后，由未撰写相应分组英文的另一位审阅者，对全部721人逐项复核；覆盖早期138人、十九世纪125人、诺奖230人、现代204人、实验补充10人及场论补充14人。逐项比较生平语义、每条贡献、物理术语、合作者、限制条件、生卒显示、历法与争议、图片性质和来源。共享诺奖概述按120个年份单元及103个人物补充单元审阅，再逐人核对应用情况。

随后再检查生成的英文档案：清除机构名中的HTML实体、作者模板样式代码与重复标签、残留中文描述性署名和空格问题，修正误指向图片文件的许可链接；原文作者姓名及法定机构署名有意保留。英文复核表示译文与已核实中文事实集相符，不等同于对每个历史争议又重新取得独立原始档案证明。

## 文件完整性与图片边界

中英文逐人检查稳定ID、时间顺序、生卒值与精度、状态、贡献和备注对应、来源URL、图片类别及文件哈希；全部本地图片解码并核对档案链接。每版均有721份人物文字和721项本地配图引用。

新增190人的实际图片全部目视检查，发现的12项图注、分类或来源问题已修正。154个Commons来源页再次请求中124个成功、30个受到限流；限流页面仍保留先前缓存与补充核对证据，不把请求失败写成重新获取成功。最终英文生成文件另作全量输出检查，当前问题与断链均为0。

配图分为672项肖像或含本人的照片、29项后世画像或纪念形象、20项相关资料图。后两类均有醒目说明，不能作为可靠生前写生肖像。62项图片的公开网站再发布授权尚未确认，详见待补清单及逐图许可。

名录覆盖广泛但仍开放扩充；历史资料矛盾、近似日期、贡献边界及未找到可核实数字肖像的情况继续保留，不作“绝无遗漏或错误”的保证。
