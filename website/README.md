# 物理学先驱网页

网页使用已复核的中英文档案，按出生时间展示人物；点击肖像或人物条目查看完整档案，可按姓名和研究领域搜索，并切换中文、英文。

采用黑白灰、系统字体、细分隔线与简洁信息层次，按科研资料阅读习惯组织正文和编号参考文献。搜索同时匹配中英文姓名及两版研究领域，忽略大小写和拉丁重音；领域和年代可以联合筛选。切换语言会保留当前人物与筛选条件。支持键盘导航、Esc关闭档案和手机布局。

## 本地浏览

macOS可在Finder中双击 `preview.command`：它会选择一个可用的本地端口并在默认浏览器中打开网页，关闭时在终端按 `Ctrl+C`。也可在项目根目录运行：

```bash
python3 website/serve.py
```

打开构建结果中的 `dist/index.html` 即可浏览。页面及双语数据使用普通脚本加载，不依赖后端、在线字体、第三方图片服务或 `fetch()`，因此也支持直接双击 HTML 文件。

也可以通过本地服务器预览，在本目录执行：

```bash
python3 -m http.server 8765 --directory dist --bind 127.0.0.1
```

然后访问 [本地网页](http://127.0.0.1:8765/)；按 `Ctrl+C` 停止服务器。若8765端口已使用，可以换一个端口。

## 文件与维护

| 文件 | 内容 |
| --- | --- |
| `src/` | 网页界面源文件 |
| `dist/` | 可独立复制或部署的完整静态网页 |
| `dist/data/archive.js` | 从两版档案生成的完整双语展示数据 |
| `dist/portraits/` | 网页引用的本地图片 |
| `dist/build-report.json` | 人数、图片分类、授权状态和数据源校验值 |

档案更新后，在项目根目录运行：

```bash
python3 scripts/build_website.py
```

构建器先核对两版的人物ID、时间顺序、日期值与精度、生死状态、来源URL、图片类型和实际文件校验值，再整体生成输出。请编辑 `src/` 与档案源数据；`dist/` 是生成目录，重新构建会同步替换其中内容。

网页保留约年、来源冲突、后世画像和资料图说明。部分图片尚未确认可用于公开网站再发布，详情见人物完整档案中的权利说明及原项目的逐图来源清单；本地生成网页不改变图片原有许可。

## 验证

运行 `node --test website/tests/search.test.cjs`（从项目根目录），可检查真实721人数据的双语搜索、年代边界、完整内容、URL状态、语言切换和键盘焦点。浏览器已验证桌面、手机布局、肖像档案、筛选、语言切换、未知生死状态、资料图说明及浏览器后退。

内置浏览器只允许HTTP(S)，因此浏览器验证使用本地HTTP；直接双击HTML的路径由无模块、无网络请求的脚本结构支持，未在内置浏览器中实测。网站无需在线字体或外部脚本。网页源文件在 `src/`，生成结果在 `dist/`。
