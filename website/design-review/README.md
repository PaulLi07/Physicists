# 物理学先驱：贡献年代与突破指数

独立本地网页源文件。正式`website/src/`及`website/dist/`页面未替换，本轮只本地更新。

## 预览

双击`preview.command`，或在项目根目录运行：

```bash
python3 website/serve.py --design-review
```

启动和刷新首页会自动检查成果、期刊资料和估计模块，并按需重算。新增人物先运行原有`python3 scripts/build_website.py`，无需改时间轴源码。Ctrl+C结束预览。
