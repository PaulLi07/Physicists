# 物理学先驱：贡献年代与突破指数

本轮在独立本地样稿内实现，正式网页 `website/src/`、`website/dist/` 的页面源码未被替换，本轮不推送GitHub。

## 运行

```bash
python3 website/serve.py --design-review
```

或双击同目录 `preview.command`。预览启动和刷新首页会自动检查成果源数据，必要时重算指数。新增人物资料先运行原有 `python3 scripts/build_website.py`，随后刷新即可纳入；无需改时间轴源码。Ctrl+C结束服务。

## 已实现的展示

- 暗红、黑色、中性灰；列表最大680px，固定48px行高（窄屏46px），姓名16px深色。删去方案说明、展开示例、设计预览和悬停操作提示。
- 当前语言只显示对应姓名；搜索仍可输入中文或英文。
- 肖像和简介在右侧固定预览卡显示，图片完整包含、不裁切。当前条目轻微突出，不改变列表几何；hover不会设置scrollTop、自动滚入视图或聚焦。
- 时间轴采用圆点与短横线游标，指针捕获与逐帧映射支持连续拖动，正文滚轮反向同步，键盘上下键/Home/End/PageUp/PageDown也可导航。点击年份可查年度成果，点击指数名称可查计算定义。
- 为与成果密度共用同一日历，目录按代表性贡献年定位；生卒日期保留在预览和完整档案。每人只出现一次，缺乏可靠贡献日期的归入待考。
- 纵轴自适应分段并标断点；横轴是统一线性刻度的加权成果点/年，颜色是贡献人物密度。压缩多个年份时用年度平均值。
- 档案保留生平、贡献、史料争议、来源与图像署名；资料图/后世形象显式说明。支持中英文与减少动态效果偏好。

## 指数与成果资料

原始成果位于 `data/breakthrough/events-*.json`。每条成果保留双语标题、日期、人物、领域、权重、理由与来源。完整方法见 `data/breakthrough/README.md`，逐年输出见 `data/breakthrough/yearly-index.json`。图反映本站选录成果，不声称穷尽全部物理史。

## 检查

```bash
node --test website/design-review/tests/*.test.cjs
```

覆盖加权成果守恒、增加成果/权重的正向影响、共同作者去重、区间日期、BCE/CE无0年、待考记录、压缩均值、动态范围及连续滚动逆映射。浏览器实测记录和最终截图在 `qa-v3.json` 与 `screenshots/`。

当前版本：342项成果，332项可定年，其中329项参与指数；373位人物具有贡献年代锚点，348位归入待考。后者仍可搜索并查看完整档案。最新人物代表年份之后，以年度成果行补齐导航至2026年；筛选时无匹配人物的年份仍可查看全库指数。进入纯待考区会清除旧年份游标。
